# Reporting Phishing and Security Incidents

## Suspicious emails
Do not click links or open attachments in a suspicious email. Use the "Report Phishing" button in Outlook, which sends it to the Security Operations Center (SOC) and removes it from your mailbox.

## If you clicked a link or entered your password
Disconnect from the network (turn off Wi-Fi), then contact the Service Desk immediately; this is handled as a P1 incident. Reset your SSO password from a different, trusted device.

## Malware warnings
If Defender shows a malware alert, do not dismiss it. Disconnect from the network and report it. The SOC responds to P1 security incidents within 15 minutes, 24/7.
