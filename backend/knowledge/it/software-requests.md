# Software Requests and Licensing

## Pre-approved software
Pre-approved software installs from Software Center within 2 hours without approval. This includes Slack, Zoom, Visual Studio Code, Python, Docker Desktop, Postman, Figma and Tableau Reader.

## Other software
Software outside the catalog needs a license review by Software Asset Management, which takes 2 to 3 business days. Paid licenses above USD 500 per year also need your manager's approval. Provide the product name, version, and a business justification.

## Administrator rights
Standard accounts do not have local administrator rights. Time-bound admin access for up to 72 hours can be requested through Privileged Access Management and always requires manager approval. All privileged sessions are recorded.
